# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately by
using GitHub private vulnerability reporting (Security tab, "Report a vulnerability") rather than opening a public issue.
Include as much detail as possible (steps to reproduce, affected
component/version). This is a small personal project, so response times are
best-effort.

## Notes

This project never requires or stores real FPL (Fantasy Premier League)
login credentials. Any FPL identifiers used (manager ID, H2H league ID) are
public numeric IDs, not secrets.
